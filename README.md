## 🛠 Local Development

### Backend

```bash
cd backend

# Install dependencies
pip install -r requirements.txt

# Set your NASA API key (free at https://api.nasa.gov)
export NASA_API_KEY=your_key_here

# Run the server
uvicorn main:app --reload

# API docs available at:
# http://localhost:8000/docs
```

### Train the ML Model (optional, Phase 2)

```bash
pip install scikit-learn xgboost shap pandas
python train_model.py
# Outputs: model.pkl + classification report + SHAP feature importance
```

### Frontend

Open `frontend/index.html` in a browser, or serve locally:

```bash
cd frontend
python -m http.server 8080
# Then open http://localhost:8080
```

> **Important**: Update `API_BASE` in `index.html` to point to your local or deployed backend.

### Run Tests

```bash
cd backend
pytest tests/ -v
```

### Docker

```bash
cd backend
docker build -t asteroid-api .
docker run -p 8000:8000 -e NASA_API_KEY=your_key asteroid-api
```

## 🌐 Deployment

### Backend → Render (free tier)

1. Push code to GitHub
2. Go to [render.com](https://render.com) → New Web Service
3. Connect your repo, set **Root Directory** to `backend`
4. Build command: `pip install -r requirements.txt`
5. Start command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
6. Add environment variable: `NASA_API_KEY = your_key_here`

### Frontend → GitHub Pages

1. Enable GitHub Pages on your repo (Settings → Pages → main branch)
2. Update `API_BASE` in `frontend/index.html` to your Render URL
3. Access at `https://YOUR_USERNAME.github.io/asteroid-impact-detection/frontend/`

## 📡 API Reference

| Endpoint | Method | Description |
|---|---|---|
| `/calculate` | POST | Compute all impact effects + risk scores |
| `/nasa/today` | GET | Today's near-Earth objects (closest 10) |
| `/nasa/asteroid/{id}` | GET | Full details for a specific asteroid |
| `/nasa/search?name=` | GET | Search asteroids by name |
| `/health` | GET | System health check |
| `/docs` | GET | Interactive Swagger UI |

### Example: Calculate Impact

```bash
curl -X POST https://YOUR-APP.onrender.com/calculate \
  -H "Content-Type: application/json" \
  -d '{
    "mass_tons": 500000,
    "velocity_kms": 20,
    "target_material": "rock",
    "diameter_km": 0.15,
    "miss_distance_km": 384400
  }'
```

**Response includes**: kinetic energy, crater diameter, blast/shock/thermal radii, severity, Torino scale level, Palermo scale, hazard probability, and scientific insights.

## 🤖 ML Model

The hazard classifier is trained on NASA's publicly labeled NEO dataset (`is_potentially_hazardous_asteroid`).

**Features used**:
- Estimated diameter (km)
- Relative velocity (km/s)
- Miss distance (km + AU)
- Kinetic energy proxy (Mt TNT)
- Orbital eccentricity
- Inclination (degrees)
- Perihelion distance (AU)
- Semi-major axis (AU)

**Model**: XGBoost with class-weight balancing  
**Explainability**: SHAP TreeExplainer for per-prediction feature attribution

Run `train_model.py` to retrain on fresh NASA data and view the SHAP importance chart.

## 📚 Scientific Background

- **Torino Scale**: An integer scale (0–10) used by the IAU to communicate impact risk to the public. Defined by the International Astronomical Union in 1999.
- **Palermo Scale**: A logarithmic scale comparing impact probability to background annual impact frequency. Negative values indicate below-background risk.
- **Physics formulas**: Based on standard planetary impact scaling laws (Melosh 1989, Collins 2005).
- **NASA NeoWs**: The Near-Earth Object Web Service, maintained by NASA's Center for Near Earth Object Studies (CNEOS).
